# viewrr-web

Web + TV client for [viewrr](https://github.com/viewrr/viewrr) — Vue 3, Tailwind CSS +
Tailwind Plus, **Apple-TV design language**.

Status: design-system seed. Vue app scaffold is [#103](https://github.com/viewrr/viewrr/issues/103).

- **[DESIGN.md](DESIGN.md)** — design system (principles, tokens, components).
- **[design/index.html](design/index.html)** — living Apple-TV mock (open in a browser).
- **[design/tokens.css](design/tokens.css)** / **[tokens.json](design/tokens.json)** — design tokens.

Tracked under [Phase 19: Clients](https://github.com/viewrr/viewrr/milestone/18). Decisions:
[ADR-0005](https://github.com/viewrr/viewrr/blob/main/docs/adr/0005-client-stack.md).
